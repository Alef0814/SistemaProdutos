# SistemaProdutos

API REST de gerenciamento de produtos com arquitetura em camadas.

## Tecnologias
- C# / ASP.NET Core
- Entity Framework Core
- SQL Server
- Swagger

## Arquitetura
- Controllers → recebe requisições
- Services → regras de negócio
- DTOs → transferência de dados
- Models → entidades
- Data → contexto do banco

## Funcionalidades
- Listar produtos
- Buscar por Id
- Cadastrar produto
- Atualizar produto
- Remover produto
